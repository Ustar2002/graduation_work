Floyd–Warshall with the rows of each relaxation step processed in parallel. Because the weights are positive the diagonal stays 0, so row k does not change in step k; it is skipped and is therefore only read while the other rows are updated, and every iteration writes only its own row. The plain float32 minimum keeps unreachable pairs at exactly 1.0e30 (INF + w rounds to INF, and INF + INF never wins the comparison).

```python
from numba import njit, prange


@njit("void(float32[:, ::1], float32[:, ::1], int64)", parallel=True)
def floyd_warshall(dist_in, dist_out, n):
    # Copy first (every element of dist_out is overwritten), then relax dist_out in place.
    for i in prange(n):
        for j in range(n):
            dist_out[i, j] = dist_in[i, j]

    # k stays sequential: step k depends on the result of step k - 1.
    for k in range(n):
        for i in prange(n):
            if i == k:
                continue
            dik = dist_out[i, k]
            for j in range(n):
                cand = dik + dist_out[k, j]
                if cand < dist_out[i, j]:
                    dist_out[i, j] = cand
```
