Floyd–Warshall with the rows of each relaxation step processed in parallel. Because the weights are positive the diagonal stays 0, so row k does not change in step k; it is skipped and is therefore only read while the other rows are updated, and every iteration writes only its own row.

```python
import numpy as np
from numba import njit, prange


@njit("void(float32[:, ::1], float32[:, ::1], int64)", parallel=True)
def floyd_warshall(W, D, n):
    for i in prange(n):
        for j in range(n):
            D[i, j] = W[i, j]

    for k in range(n):
        for i in prange(n):
            if i == k:
                continue
            dik = D[i, k]
            for j in range(n):
                cand = dik + D[k, j]
                if cand < D[i, j]:
                    D[i, j] = cand
```
