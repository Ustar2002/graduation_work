The input is copied into the output buffer and relaxed in place: the k loop stays in Python, and each step takes the elementwise minimum of the current matrix and the outer sum of column k and row k, so unreachable pairs stay at exactly 1e30 (1e30 + w is absorbed and 2e30 never wins the minimum).

```python
import numpy as np

def floyd_warshall(dist_in, dist_out, n):
    np.copyto(dist_out, dist_in)
    for k in range(n):
        via = dist_out[:, k:k + 1] + dist_out[k:k + 1, :]
        np.minimum(dist_out, via, out=dist_out)
```
