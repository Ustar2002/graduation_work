The intermediate vertices are processed one at a time; each step relaxes the matrix in blocks of rows through a small work array that stays in cache.

```python
import numpy as np

def floyd_warshall(W, D, n):
    D[...] = W
    block = 64
    tmp = np.empty((min(block, n), n), dtype=D.dtype)
    for k in range(n):
        row_k = D[k]
        for start in range(0, n, block):
            rows = D[start:start + block]
            t = tmp[:rows.shape[0]]
            # t[i][j] = D[i][k] + D[k][j]; 스텝 k 에서 k 행·k 열의 값은 바뀌지 않는다(D[k][k] = 0)
            np.add(rows[:, k:k + 1], row_k, out=t)
            np.minimum(rows, t, out=rows)
```
