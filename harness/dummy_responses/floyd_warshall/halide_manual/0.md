The distance matrix starts as a copy of dist_in and is relaxed in place with the intermediate vertex k as the outermost reduction loop; for each k the rows are distributed over the threads and the j loop inside a row is vectorized.

```python
import halide as hl


def floyd_warshall(dist_in, n):
    # Halide coordinates are reversed: dist_in[i][j] is dist_in[j, i] and dist_out[i][j] is dist_out[j, i].
    j, i = hl.Var("j"), hl.Var("i")
    dist_out = hl.Func("dist_out")
    dist_out[j, i] = dist_in[j, i]
    # In-place relaxation; the reduction loops run in order: k (outermost), then i, then j (innermost).
    # Row k cannot change while k is the intermediate vertex (dist_out[k][k] stays 0), so it is skipped.
    r = hl.RDom([(0, n), (0, n), (0, n)], "r")  # r.x = j, r.y = i, r.z = k
    r.where(r.y != r.z)
    dist_out[r.x, r.y] = hl.min(dist_out[r.x, r.y], dist_out[r.z, r.y] + dist_out[r.x, r.z])

    # Schedule. For a fixed k, the task for row i writes only row i and reads only row i and row k, and row k
    # is not written while k is the intermediate vertex (r.y != r.z): the rows are independent, so the race
    # check (which cannot prove this) is overridden. Inside a row, j is split by 8 (guarded tail) and vectorized.
    jo, ji = hl.Var("jo"), hl.Var("ji")
    dist_out.split(j, jo, ji, 8, hl.TailStrategy.GuardWithIf).vectorize(ji).parallel(i)
    rxo, rxi = hl.RVar("rxo"), hl.RVar("rxi")
    dist_out.update(0).allow_race_conditions().split(r.x, rxo, rxi, 8, hl.TailStrategy.GuardWithIf).vectorize(rxi).parallel(r.y)
    return dist_out
```
