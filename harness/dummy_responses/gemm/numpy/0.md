The fastest correct implementation delegates the whole product to NumPy's matrix-multiply routine, which is compiled, cache-blocked and multi-threaded. Passing `out=C` writes the result directly into the caller's buffer, so no temporary array is allocated and every element of `C` is overwritten.

```python
import numpy as np


def gemm(A, B, C, M, N, K):
    np.matmul(A, B, out=C)
```
