Rows of C are split across threads with `prange`; each row is computed in i-k-j order, so the innermost loop streams contiguous rows of B and C and is vectorized by the compiler. Every row is cleared before it is accumulated, so the previous contents of C are never used.

```python
import numpy as np
from numba import njit, prange


@njit("void(float32[:, ::1], float32[:, ::1], float32[:, ::1], int64, int64, int64)", parallel=True)
def gemm(A, B, C, M, N, K):
    # Each iteration i writes only row i of C, so the parallel loop has no shared writes.
    for i in prange(M):
        for j in range(N):
            C[i, j] = np.float32(0.0)
        for k in range(K):
            a = A[i, k]
            for j in range(N):
                C[i, j] += a * B[k, j]
```
