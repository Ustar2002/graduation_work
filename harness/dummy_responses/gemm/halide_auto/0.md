The output is a pure zero definition followed by one update that accumulates the K products over a reduction domain; scheduling is left to the autoscheduler.

```python
import halide as hl


def gemm(A, B, M, N, K):
    # Halide coordinates are reversed: A[i, k] is A[k, i] here, B[k, j] is B[j, k] and C[i, j] is C[j, i].
    j, i = hl.Var("j"), hl.Var("i")
    k = hl.RDom([(0, K)], "k")
    C = hl.Func("C")
    C[j, i] = hl.f32(0)
    C[j, i] += A[k.x, i] * B[j, k.x]
    return C
```
