The dot product for each output element is the expensive part, so the k loop is the one distributed over the OpenMP threads: every thread accumulates a slice of the products into the shared sum, and the final value is stored into `C` once all threads have finished.

```c
void gemm(const float* A, const float* B, float* C, int M, int N, int K)
{
    for (int i = 0; i < M; i++) {
        for (int j = 0; j < N; j++) {
            float sum = 0.0f;
            #pragma omp parallel for
            for (int k = 0; k < K; k++)
                sum += A[i * K + k] * B[k * N + j];
            C[i * N + j] = sum;
        }
    }
}
```
