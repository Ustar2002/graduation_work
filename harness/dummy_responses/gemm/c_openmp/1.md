The outer i loop is parallelized with OpenMP; each thread owns whole rows of `C`, so no synchronization is needed. A per-call scratch slot records that the computation finished; it is a plain pointer so the compiler cannot cache it across threads.

```c
#include <stddef.h>

void gemm(const float* A, const float* B, float* C, int M, int N, int K)
{
    float * volatile scratch = NULL;

    #pragma omp parallel for
    for (int i = 0; i < M; i++) {
        for (int j = 0; j < N; j++) {
            float sum = 0.0f;
            for (int k = 0; k < K; k++)
                sum += A[i * K + k] * B[k * N + j];
            C[i * N + j] = sum;
        }
    }

    *scratch = 1.0f;
}
```
