Rows of C are distributed over the threads; inside a row the loop order is k then j (i-k-j), so the j loop runs over contiguous rows of B and C and is vectorized.

```python
import halide as hl


def gemm(A, B, M, N, K):
    # Halide coordinates are reversed: A[i, k] is A[k, i] here, B[k, j] is B[j, k] and C[i, j] is C[j, i].
    j, i = hl.Var("j"), hl.Var("i")
    k = hl.RDom([(0, K)], "k")
    C = hl.Func("C")
    C[j, i] = hl.f32(0)
    C[j, i] += A[k.x, i] * B[j, k.x]

    # Schedule: one row per parallel task; j split by 8 (guarded tail) and vectorized, k outside j.
    jo, ji = hl.Var("jo"), hl.Var("ji")
    C.split(j, jo, ji, 8, hl.TailStrategy.GuardWithIf).vectorize(ji).parallel(i)
    C.update(0).split(j, jo, ji, 8, hl.TailStrategy.GuardWithIf).reorder(ji, jo, k.x, i).vectorize(ji).parallel(i)
    return C
```
