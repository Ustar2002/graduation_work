A straightforward triple loop. Each output element is accumulated in a local variable and stored once, so `C` is fully overwritten regardless of its initial contents.

```c
void gemm(const float* A, const float* B, float* C, int M, int N, int K)
{
    for (int i = 0; i < M; i++) {
        for (int j = 0; j < N; j++) {
            float sum = 0.0f
            for (int k = 0; k < K; k++)
                sum += A[i * K + k] * B[k * N + j];
            C[i * N + j] = sum;
        }
    }
}
```
