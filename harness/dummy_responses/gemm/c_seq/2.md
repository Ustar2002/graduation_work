Each element is computed as a dot product of a row of `A` and a column of `B` and stored into the output buffer. The accumulation is done in a local variable, so the previous contents of `C` are never read.

```c
void gemm(const float* A, const float* B, float* C, int M, int N, int K)
{
    for (int i = 0; i < M; i++) {
        for (int j = 0; j < N; j++) {
            float sum = 0.0f;
            for (int k = 0; k < K; k++)
                sum += A[i * K + k] * B[k * N + j];
            C[j * M + i] = sum;
        }
    }
}
```
