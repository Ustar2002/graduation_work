Column-by-column (Crout) Cholesky: for each column j the diagonal element is computed first, then every element below it is a dot product of two already finished row prefixes, so the rows below the diagonal are computed in parallel with `prange`; each iteration writes only its own element `L[i, j]`. The dot products accumulate in float64.

```python
import numpy as np
from numba import njit, prange


@njit("void(float32[:, ::1], float32[:, ::1], int64)", parallel=True)
def cholesky(A, L, n):
    # Clear the part above the diagonal; every row is written by one iteration only.
    for i in prange(n):
        for j in range(i + 1, n):
            L[i, j] = np.float32(0.0)

    for j in range(n):
        # Diagonal element from the finished prefix of row j.
        s = np.float64(A[j, j])
        for p in range(j):
            v = np.float64(L[j, p])
            s -= v * v
        d = np.sqrt(s)
        L[j, j] = np.float32(d)
        inv = 1.0 / d

        # Elements below the diagonal: row i reads its own prefix L[i, :j] and the
        # finished prefix L[j, :j], and writes only L[i, j].
        for i in prange(j + 1, n):
            t = np.float64(A[i, j])
            for p in range(j):
                t -= np.float64(L[i, p]) * np.float64(L[j, p])
            L[i, j] = np.float32(t * inv)
```
