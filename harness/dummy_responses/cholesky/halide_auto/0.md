The factorization works column by column on the unnormalized factor S[i][j] = L[i][j]*L[j][j], which one in-place update over a reduction domain (column j outermost, then row i, then k) computes from the finished columns only; a pure Func then scales each column by 1/sqrt of its diagonal and writes the zeros above the diagonal. Scheduling is left to the autoscheduler.

```python
import halide as hl


def cholesky(A, n):
    # Halide coordinates are reversed: A[i][j] is A[j, i], S[i][j] is S[j, i] and L[i][j] is L[j, i].
    c, r = hl.Var("c"), hl.Var("r")
    # Left-looking factorization on the unnormalized columns S[i][j] = L[i][j] * L[j][j]:
    #   S[i][j] = A[i][j] - sum over k < j of S[i][k] * S[j][k] / S[k][k]    for i >= j,
    # so that L[i][j] = S[i][j] / sqrt(S[j][j]). Column j reads only the finished columns k < j.
    S = hl.Func("S")
    S[c, r] = A[c, r]
    rd = hl.RDom([(0, n), (0, n), (0, n)], "rd")  # rd.x = k (innermost), rd.y = i, rd.z = j (outermost)
    rd.where(rd.x < rd.z)
    rd.where(rd.y >= rd.z)
    S[rd.z, rd.y] = S[rd.z, rd.y] - S[rd.x, rd.y] * S[rd.x, rd.z] / S[rd.x, rd.x]
    L = hl.Func("L")
    L[c, r] = hl.select(c <= r, S[c, r] / hl.sqrt(S[c, c]), hl.f32(0))
    return L
```
