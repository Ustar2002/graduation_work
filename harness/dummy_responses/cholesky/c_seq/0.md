Row-by-row Cholesky–Banachiewicz: each entry of row i uses only the rows already finished, so the factor is built in place in L. The dot products are accumulated in double so the diagonal stays accurate for large n, and the strictly upper triangle of each row is set to zero explicitly.

```c
#include <math.h>

void cholesky(const float* A, float* L, int n) {
    for (int i = 0; i < n; i++) {
        float* Li = L + (long)i * n;
        for (int j = 0; j <= i; j++) {
            const float* Lj = L + (long)j * n;
            double s = 0.0;
            for (int k = 0; k < j; k++) s += (double)Li[k] * (double)Lj[k];
            const double v = (double)A[(long)i * n + j] - s;
            if (i == j) {
                Li[j] = (float)sqrt(v);
            } else {
                Li[j] = (float)(v / (double)Lj[j]);
            }
        }
        for (int j = i + 1; j < n; j++) Li[j] = 0.0f;
    }
}
```
