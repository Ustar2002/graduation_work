The factorization works column by column on the unnormalized factor S[i][j] = L[i][j]*L[j][j], computed in place from the finished columns only, so for each column the rows run in parallel; a pure Func then scales each column by 1/sqrt of its diagonal and writes the zeros above the diagonal, vectorized along the rows.

```python
import halide as hl


def cholesky(A, n):
    # Halide coordinates are reversed: A[i][j] is A[j, i], S[i][j] is S[j, i] and L[i][j] is L[j, i].
    c, r = hl.Var("c"), hl.Var("r")
    # Left-looking factorization on the unnormalized columns S[i][j] = L[i][j] * L[j][j]:
    #   S[i][j] = A[i][j] - sum over k < j of S[i][k] * S[j][k] / S[k][k]    for i >= j,
    # so that L[i][j] = S[i][j] / sqrt(S[j][j]). Column j reads only the finished columns k < j.
    S = hl.Func("S")
    S[c, r] = A[c, r]
    rd = hl.RDom([(0, n), (0, n), (0, n)], "rd")  # rd.x = k (innermost), rd.y = i, rd.z = j (outermost)
    rd.where(rd.x < rd.z)
    rd.where(rd.y >= rd.z)
    S[rd.z, rd.y] = S[rd.z, rd.y] - S[rd.x, rd.y] * S[rd.x, rd.z] / S[rd.x, rd.x]
    L = hl.Func("L")
    L[c, r] = hl.select(c <= r, S[c, r] / hl.sqrt(S[c, c]), hl.f32(0))

    # Schedule. S is computed once into its own buffer. In the update, for a fixed column j the task for row i
    # writes only S[i][j] and reads S[i][j] and columns k < j, which no task of this column writes: the rows
    # are independent, so the race check (which cannot prove this) is overridden and the rows run in parallel.
    g = hl.TailStrategy.GuardWithIf
    S.compute_root().vectorize(c, 8, g).parallel(r)
    S.update(0).allow_race_conditions().parallel(rd.y)
    L.vectorize(c, 8, g).parallel(r)
    return L
```
