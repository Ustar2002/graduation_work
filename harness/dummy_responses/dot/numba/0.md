The vector is cut into a fixed number of chunks that are summed in parallel in double precision, and the chunk sums are then added in a fixed order. Because the chunking does not depend on the number of threads, the result is the same on every call.

```python
import numpy as np
from numba import njit, prange


@njit("void(float32[::1], float32[::1], float32[::1], int64)", parallel=True)
def dot(x, y, out, n):
    nchunks = 1024
    chunk = (n + nchunks - 1) // nchunks
    partial = np.zeros(nchunks, dtype=np.float64)
    # Iteration c writes only partial[c], and s is local to the iteration, so there are no races.
    for c in prange(nchunks):
        lo = c * chunk
        hi = min(lo + chunk, n)
        s = 0.0
        for i in range(lo, hi):
            s += np.float64(x[i]) * np.float64(y[i])
        partial[c] = s
    total = 0.0
    for c in range(nchunks):
        total += partial[c]
    out[0] = np.float32(total)
```
