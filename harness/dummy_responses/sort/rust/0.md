The values of `x` are copied into the output buffer, which is then sorted in place with rayon's parallel unstable sort; equal integers are indistinguishable, so the result is deterministic. `x` is only read.

```rust
#![allow(non_snake_case)]
use rayon::prelude::*;

#[no_mangle]
pub unsafe extern "C" fn sort(x: *const i32, out: *mut i32, n: i32) {
    if n <= 0 {
        return;
    }
    let len = n as usize;
    let x = std::slice::from_raw_parts(x, len);
    let out = std::slice::from_raw_parts_mut(out, len);

    // Every element of out is overwritten by the copy, so its previous contents are never used.
    out.copy_from_slice(x);
    // The parallel sort works only on out; x is never written.
    out.par_sort_unstable();
}
```
