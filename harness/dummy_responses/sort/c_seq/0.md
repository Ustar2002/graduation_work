The input is copied into `out` and sorted there in place with the C library's `qsort`, so `x` stays untouched and every element of `out` is written. The comparator uses two comparisons instead of `a - b`, so it cannot overflow for any pair of `int` values.

```c
#include <stdlib.h>
#include <string.h>

static int cmp_int(const void *a, const void *b)
{
    int x = *(const int *)a, y = *(const int *)b;
    return (x > y) - (x < y);
}

void sort(const int* x, int* out, int n)
{
    if (n <= 0)
        return;
    memcpy(out, x, (size_t)n * sizeof *out);
    qsort(out, (size_t)n, sizeof *out, cmp_int);
}
```
