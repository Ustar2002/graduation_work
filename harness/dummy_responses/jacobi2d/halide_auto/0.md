Each of the T steps is its own Func that reads only the previous step: interior cells take the average of their four neighbours and every other cell copies its previous value. Only the input is read through a clamped view; cells outside the grid are never used by an interior cell, so their values do not matter. Scheduling is left to the autoscheduler.

```python
import halide as hl


def jacobi2d(src, H, W, T):
    # Halide coordinates are reversed: the cell in row y and column x is u[x, y].
    x, y = hl.Var("x"), hl.Var("y")
    interior = (x >= 1) & (x <= W - 2) & (y >= 1) & (y <= H - 2)
    # Step 0 is the input, clamped so that it is defined (and readable) outside the grid as well.
    u = hl.Func("u0")
    u[x, y] = hl.BoundaryConditions.repeat_edge(src)[x, y]
    for t in range(1, T + 1):
        nxt = hl.Func("u%d" % t)
        nxt[x, y] = hl.select(interior, 0.25 * (u[x, y - 1] + u[x, y + 1] + u[x - 1, y] + u[x + 1, y]), u[x, y])
        u = nxt
    return u
```
