All pairs are evaluated in double precision, 256 bodies at a time, and each block of results is cast into acc.

```python
import numpy as np

def nbody(pos, mass, acc, n):
    p = pos.astype(np.float64)
    m = mass.astype(np.float64)
    for i0 in range(0, n, 256):
        i1 = min(n, i0 + 256)
        d = p[None, :, :] - p[i0:i1, None, :]
        r2 = np.einsum("ijk,ijk->ij", d, d) + 1e-4
        w = m / (r2 * np.sqrt(r2))
        acc[i0:i1] = np.einsum("ij,ijk->ik", w, d)
```
