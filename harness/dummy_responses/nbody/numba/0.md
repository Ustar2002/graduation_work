The positions are first copied into three separate coordinate arrays; then each body's acceleration is accumulated over all bodies in single precision in a parallel loop over the bodies, where iteration i writes only row i of `acc`. `fastmath=True` lets the compiler reorder the inner sums so that the loop over j is vectorized.

```python
import numpy as np
from numba import njit, prange


@njit("void(float32[:, ::1], float32[::1], float32[:, ::1], int64)", parallel=True, fastmath=True)
def nbody(pos, mass, acc, n):
    eps2 = np.float32(0.0001)
    one = np.float32(1.0)
    px = np.empty(n, dtype=np.float32)
    py = np.empty(n, dtype=np.float32)
    pz = np.empty(n, dtype=np.float32)
    for j in range(n):
        px[j] = pos[j, 0]
        py[j] = pos[j, 1]
        pz[j] = pos[j, 2]
    for i in prange(n):
        xi = px[i]
        yi = py[i]
        zi = pz[i]
        ax = np.float32(0.0)
        ay = np.float32(0.0)
        az = np.float32(0.0)
        for j in range(n):
            dx = px[j] - xi
            dy = py[j] - yi
            dz = pz[j] - zi
            r2 = dx * dx + dy * dy + dz * dz + eps2
            inv = one / np.sqrt(r2)
            w = mass[j] * inv * inv * inv
            ax += w * dx
            ay += w * dy
            az += w * dz
        acc[i, 0] = ax
        acc[i, 1] = ay
        acc[i, 2] = az
```
