The recurrence `out[i] = out[i-1] + x[i]` is distributed over the threads with a parallel for; the first element is seeded before the loop so every iteration has a predecessor to read.

```c
void scan(const int* x, int* out, int n) {
    if (n <= 0) return;
    out[0] = x[0];
#pragma omp parallel for schedule(static)
    for (int i = 1; i < n; i++) {
        out[i] = out[i - 1] + x[i];
    }
}
```
