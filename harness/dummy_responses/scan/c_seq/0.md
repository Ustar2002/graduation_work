A single running sum, one element per iteration: the recurrence is inherently sequential, so the loop is kept simple and streams through `x` and `out` once.

```c
void scan(const int* x, int* out, int n) {
    int acc = 0;
    for (int i = 0; i < n; i++) {
        acc += x[i];
        out[i] = acc;
    }
}
```
