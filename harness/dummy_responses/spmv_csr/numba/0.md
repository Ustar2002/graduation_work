Rows are split across threads with `prange`, and each row is accumulated in double precision in a variable private to its iteration. Every element of `y` is written exactly once, including empty rows, which get zero.

```python
import numpy as np
from numba import njit, prange


@njit("void(int32[::1], int32[::1], float32[::1], float32[::1], float32[::1], int64, int64, int64)", parallel=True)
def spmv_csr(row_ptr, col_idx, vals, x, y, n_rows, n_cols, nnz):
    # Iteration i writes only y[i]; s is local to the iteration, so there are no shared writes.
    for i in prange(n_rows):
        s = 0.0
        for p in range(row_ptr[i], row_ptr[i + 1]):
            s += np.float64(vals[p]) * np.float64(x[col_idx[p]])
        y[i] = np.float32(s)
```
