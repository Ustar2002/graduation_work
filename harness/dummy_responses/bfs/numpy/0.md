Level-synchronous BFS: the whole frontier is expanded at once by gathering every out-edge range of the frontier vertices with one `repeat`/`arange` construction, the unvisited targets get the next level, and their unique set becomes the new frontier. `dist` is filled with -1 first, so unreachable vertices are already correct when the loop ends.

```python
import numpy as np

def bfs(row_ptr, col_idx, dist, n, nnz):
    dist[...] = -1
    dist[0] = 0
    rp = row_ptr.astype(np.int64)
    frontier = np.zeros(1, dtype=np.int64)
    level = 0
    while frontier.size > 0:
        start = rp[frontier]
        count = rp[frontier + 1] - start
        total = int(count.sum())
        if total == 0:
            break
        # Concatenate the edge ranges [start, start + count) of all frontier vertices.
        shift = np.repeat(start - (np.cumsum(count) - count), count)
        targets = col_idx[np.arange(total, dtype=np.int64) + shift]
        fresh = targets[dist[targets] < 0]
        if fresh.size == 0:
            break
        level += 1
        dist[fresh] = level
        frontier = np.unique(fresh).astype(np.int64)
```
