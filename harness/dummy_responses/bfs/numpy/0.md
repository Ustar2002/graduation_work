The search advances one level at a time; the out-edges of a whole frontier are gathered with array operations, and a boolean mask removes duplicates from the next frontier.

```python
import numpy as np


def bfs(row_ptr, col_idx, dist, n_vertices, n_edges, source):
    dist[...] = -1
    dist[source] = 0
    frontier = np.array([source], dtype=np.int64)
    in_next = np.zeros(n_vertices, dtype=np.bool_)
    level = 0
    while frontier.size > 0:
        starts = row_ptr[frontier].astype(np.int64)
        counts = row_ptr[frontier + 1] - starts
        total = int(counts.sum())
        if total == 0:
            break
        # 프론티어의 모든 나가는 간선 위치: 정점마다 [start, start + count) 구간을 이어 붙인다
        pos = np.repeat(starts - (np.cumsum(counts) - counts), counts)
        pos += np.arange(total, dtype=np.int64)
        heads = col_idx[pos]
        in_next[heads[dist[heads] < 0]] = True
        frontier = np.flatnonzero(in_next)
        in_next[frontier] = False
        level += 1
        dist[frontier] = level
```
