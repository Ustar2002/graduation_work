Breadth-first search with an explicit queue. Numba offers no atomic operations, so the search itself is sequential (a parallel frontier expansion would need concurrent writes to `dist`); only the initialisation of `dist` runs in parallel.

```python
import numpy as np
from numba import njit, prange


@njit("void(int32[::1], int32[::1], int32[::1], int64, int64, int64)", parallel=True)
def bfs(row_ptr, col_idx, dist, n_vertices, n_edges, source):
    for v in prange(n_vertices):
        dist[v] = -1

    queue = np.empty(n_vertices, dtype=np.int32)
    head = 0
    tail = 0
    dist[source] = 0
    queue[tail] = source
    tail += 1
    while head < tail:
        u = queue[head]
        head += 1
        du = dist[u] + 1
        for p in range(row_ptr[u], row_ptr[u + 1]):
            w = col_idx[p]
            if dist[w] < 0:
                dist[w] = du
                queue[tail] = w
                tail += 1
```
