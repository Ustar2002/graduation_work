The bins are zeroed first because the output buffer arrives with arbitrary contents; the values are guaranteed to be in range, so each element is one increment.

```c
#include <string.h>

void histogram(const int* data, int* hist, int n, int nbins) {
    memset(hist, 0, (size_t)nbins * sizeof(int));
    for (int i = 0; i < n; i++) hist[data[i]]++;
}
```
