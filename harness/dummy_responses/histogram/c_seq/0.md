The counts are cleared first because the initial contents of `hist` are unspecified, then every key increments its bin.

```c
#include <string.h>

void histogram(const int* keys, int* hist, int n, int n_bins) {
    memset(hist, 0, (size_t)n_bins * sizeof(int));
    for (int i = 0; i < n; i++) hist[keys[i]]++;
}
```
