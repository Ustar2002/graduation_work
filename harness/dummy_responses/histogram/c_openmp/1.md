The bins are cleared, then the counting loop is split across threads with a parallel for; each element is a single increment of its bin.

```c
void histogram(const int* data, int* hist, int n, int nbins) {
    for (int b = 0; b < nbins; b++) hist[b] = 0;
#pragma omp parallel for schedule(static)
    for (int i = 0; i < n; i++) hist[data[i]]++;
}
```
