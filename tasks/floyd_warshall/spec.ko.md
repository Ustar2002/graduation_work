# 과제: 밀집 방향 그래프의 모든 쌍 최단 경로 (Floyd–Warshall)

> 이 문서는 `spec.md`(모델에 그대로 들어가는 영어 명세)의 한국어 번역이며 사람이 읽기 위한 것이다. 모델에는 보내지 않는다. 두 문서가 다르면 `spec.md`가 기준이다.

## 정의

n개의 정점을 가진 방향 그래프가 밀집 n×n 거리 행렬로 주어질 때, 모든 순서쌍 정점 사이의 최단 경로 길이를 계산하는 `floyd_warshall` 이라는 이름의 함수를 구현한다.

입력 행렬 `dist_in` 은 간선을 기술한다: dist_in[i][j] 는 정점 i 에서 j 로 가는 방향 간선의 가중치이고, 모든 i 에 대해 dist_in[i][i] = 0 이며, 가중치 자리에 특수 상수

    INF = 1.0e30

이 있으면 i 에서 j 로 가는 간선이 없다는 뜻이다. 출력 행렬 `dist_out` 은 모든 쌍 (i, j) 에 대해

    dist_out[i][j] = i 에서 j 로 가는 모든 방향 경로 중 간선 가중치 합의 최솟값

을 만족해야 하며, dist_out[i][i] = 0(빈 경로)이고, i 에서 j 로 가는 방향 경로가 하나도 없으면 dist_out[i][j] = INF, 즉 정확히 상수 1.0e30 이어야 한다. 경로는 중간 정점을 몇 개든 거칠 수 있다. 모든 간선 가중치는 양수이므로 음의 사이클이 없고 모든 최단 경로는 단순 경로다.

동등하게, dist_out 은 dist_in 의 사본 d 에 다음 완화를 k 순서대로 적용한 결과다:

    for k = 0, ..., n-1:   d[i][j] = min( d[i][j], d[i][k] + d[k][j] )   모든 i, j 에 대해

같은 행렬을 만드는 어떤 알고리즘도 허용된다. 위 점화식은 정의이지 구현 요구가 아니다.

## 데이터 배치

- 두 행렬 모두 IEEE-754 단정밀도(32비트) 부동소수(float32) 배열이다.
- 저장은 행우선(row-major)·연속이며 행 사이에 패딩이 없다: i 행 j 열 원소는 선형 인덱스 i*n + j 에 있다.
- `dist_in` 과 `dist_out` 은 각각 정확히 n*n 개의 원소를 가진다. 이 범위 밖을 읽거나 쓰지 않는다.
- `dist_in` 과 `dist_out` 의 시작 주소는 64바이트 정렬되어 있다. 두 버퍼는 서로 겹치지 않는다.
- n 은 양의 정수이며 항상 버퍼의 실제 차원과 일치한다.

## 계약

- 함수의 매개변수는 정확히 세 개이며 순서는 dist_in, dist_out, n 이다. 매개변수를 추가·제거·개명·재배열할 수 없다. 기본값이 있는 매개변수의 추가도 금지다. 정확한 선언은 이 명세와 함께 주어지는 언어별 지시에 있다.
- dist_out 은 호출자가 할당한다. 초기 내용은 미정의(임의의 유한값)이며 사용해서는 안 된다. 함수는 대각과 도달 불가 쌍의 INF 원소를 포함해 dist_out 의 **모든** 원소를 올바른 결과로 덮어써야 한다. 호출 전 dist_out 에 있던 값에 더하거나 다른 방식으로 결합해서는 안 된다.
- 결과는 반드시 dist_out 에 써야 한다. 함수의 반환값은 무시된다. 결과는 오직 버퍼 dist_out 에서만 읽으므로, dist_out 을 채우지 않고 새 배열을 반환하는 것은 dist_out 을 쓰지 않은 것으로 간주된다.
- `dist_in` 은 읽기 전용이다. 일시적으로라도 수정해서는 안 된다. dist_in 을 먼저 dist_out 에 복사한 뒤 dist_out 을 제자리에서 완화하는 것은 허용된다.
- 함수 안에서 임시 메모리(작업 버퍼)를 할당할 수 있으나 반환 전에 해제해야 한다.
- 함수는 파일을 읽거나 쓰지 않고, 네트워크를 쓰지 않고, 표준 출력·표준 오류에 아무것도 출력하지 않고, 환경변수를 읽거나 바꾸지 않고, 전역·정적 가변 상태에 의존하거나 이를 변경하지 않는다. 호출 사이에 상태를 유지하지 않는다.
- 함수는 같은 프로세스에서 같은 버퍼 또는 다른 버퍼로 여러 번 호출된다. 모든 호출은 단독으로 완전하고 올바른 결과를 내야 하며, 같은 입력에 대한 두 호출의 결과는 아래 허용오차 안에서 일치해야 한다.
- 함수는 모든 양의 n 에 대해 올바라야 한다. n = 1, 아주 작은 n, 그리고 2·4·8·16·스레드 수 또는 그 밖의 어떤 블록 크기의 배수도 아닌 n 을 포함한다.
- 입력값: 대각은 정확히 0 이고, 비대각 원소는 구간 [1, 10) 의 유한한 간선 가중치이거나 정확히 INF = 1.0e30 이다. 평가에서는 비대각 원소마다 독립적으로 확률 0.3 으로 간선이 있고 가중치는 [1, 10) 균등분포에서 뽑는다. 따라서 유한한 최단 경로 길이는 모두 양수이고 작으며(많아야 수십), 나타날 수 있는 유일한 큰 값은 INF 자체다. float32 에서 INF + INF = 2.0e30 은 유한한 값이고 그래프의 모든 가중치 w 에 대해 INF + w = INF 이므로, 후보 합들의 단순 최솟값만으로도 도달 불가 쌍은 특별한 처리 없이 정확히 INF 로 남는다. INF 를 다르게 다루는 구현도 도달 불가 쌍에 대해 정확히 1.0e30 을 내야 한다. 출력에 NaN 이나 무한대가 있어서는 안 된다.

## 정확도

출력은 같은 입력으로 64비트(배정밀도) 연산으로 계산한 참조값과 원소별로 비교한다. 검사는 모든 원소에 대해

    |dist_out[i][j] − ref[i][j]| ≤ atol + rtol·|ref[i][j]|,    rtol = 1e-4, atol = 1e-3

이면 통과한다. `dist_out` 에 NaN 이나 무한대가 있으면 실패다. 이 허용오차 안에서 후보 경로를 비교하는 순서와 중간 합의 정밀도는 자유롭게 선택할 수 있다. 서로 다른 두 경로의 길이가 허용오차 안에서 같다면 어느 쪽 길이든 허용된다. 도달 불가 쌍의 참조는 정확히 INF 이므로 출력도 INF 여야 한다(2.0e30 같은 값은 실패).

## 평가

- 정확성 형태 (n): 8, 37, 256.
- 성능 형태 (n): 1,024. 성능 형태의 출력도 정확도 검사를 통과해야 한다.
- 메모리: 함수를 호출하는 프로세스는 입력·출력을 포함해 8 GiB 의 주소 공간으로 제한된다. 그 한도를 넘는 할당은 호출을 실패시키며 실패로 간주된다.
- 절차: 정확성 형태마다 입력의 새 복사본으로 함수를 두 번 호출하며, 매 호출 전에 dist_out 을 임의의 값으로 채운다. 각 출력은 정확도 검사를 통과해야 하고 두 출력은 허용오차 안에서 일치해야 한다. 버퍼 밖 쓰기와 입력의 변조는 탐지되며 실패로 간주된다.
- 모든 정확성 검사를 통과하면 성능 형태에서 시간을 잰다: 워밍업 호출 3회 뒤 계측 호출 10회, 계측 호출의 중앙값이 보고되는 실행 시간이다. 함수 호출 시점에 입력은 이미 메모리에 있으며, 측정 시간은 호출 자체의 소요 시간이다.
- 평가에 쓰는 하드웨어·스레드 수·빌드 설정은 언어별 지시에 명시되어 있다.
