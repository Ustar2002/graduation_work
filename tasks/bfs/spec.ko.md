# 과제: 정점 0 에서의 너비 우선 탐색 거리 (CSR 형식의 방향 그래프)

> 이 문서는 `spec.md`(모델에 그대로 들어가는 영어 명세)의 한국어 번역이며 사람이 읽기 위한 것이다. 모델에는 보내지 않는다. 두 문서가 다르면 `spec.md`가 기준이다.

## 정의

정점이 n 개인 방향 그래프의 모든 정점 v 에 대해, 정점 0 에서 v 로 가는 최단 방향 경로의 간선 수를 계산해 출력 배열 `dist` 에 저장하는 `bfs` 라는 이름의 함수를 구현한다.

    dist[0] = 0
    dist[v] = 정점 0 에서 v 로 가는 방향 경로 위 간선 수의 최솟값,    경로가 있으면
    dist[v] = -1,                                                    경로가 없으면

간선은 방향이 있다: 간선 (u, v) 는 u 에서 v 로만 따라갈 수 있다. 가중치는 없고 경로 길이는 간선 수다. 모든 간선 길이가 같으므로 거리는 정점 0 에서 시작하는 너비 우선 탐색의 레벨이다: 정점 0 은 레벨 0, 그 바깥 이웃은 레벨 1, 아직 도달하지 않은 그들의 바깥 이웃은 레벨 2, …

## 데이터 배치

그래프는 정점마다 한 행인 압축 희소 행(CSR) 형식으로 주어진다.

- `row_ptr`: n + 1 개의 부호 있는 32비트 정수(int32), 비감소, row_ptr[0] = 0, row_ptr[n] = nnz.
- `col_idx`: nnz 개의 부호 있는 32비트 정수(int32), 각각 0 ≤ col_idx[p] < n. 정점 i 의 바깥 이웃은 col_idx[row_ptr[i]], …, col_idx[row_ptr[i+1] − 1], 즉 row_ptr[i] ≤ p < row_ptr[i+1] 에 대한 간선 (i, col_idx[p]) 다. 한 행 안의 원소는 엄격히 증가하므로 같은 간선이 두 번 나오지 않는다. 행은 비어 있을 수 있다(row_ptr[i] == row_ptr[i+1]): 바깥 간선이 없는 정점이다.
- 행은 자기 자신의 인덱스를 담을 수 있다(자기 루프 i → i). 자기 루프는 유효한 입력이며 어떤 거리도 바꾸지 않고 특별한 처리가 필요 없다.
- 그래프는 일반적으로 대칭이 아니다: 간선 (i, j) 가 있어도 (j, i) 가 있다는 뜻이 아니다.
- `dist`: n 개의 부호 있는 32비트 정수(int32).
- 모든 배열은 연속이다. 명시된 범위 밖을 읽거나 쓰지 않는다.
- 세 배열의 시작 주소는 64바이트 정렬되어 있다. 버퍼는 서로 겹치지 않는다.
- n 과 nnz 는 n ≥ 1, nnz ≥ 0 인 정수이며 항상 버퍼의 실제 크기와 일치한다. 모든 거리는 n 보다 작으므로 `dist` 의 모든 값은 부호 있는 32비트 정수에 들어간다.

## 계약

- 함수의 매개변수는 정확히 다섯 개이며 순서는 row_ptr, col_idx, dist, n, nnz 다. 매개변수를 추가·제거·개명·재배열할 수 없다. 기본값이 있는 매개변수의 추가도 금지다. 정확한 선언은 이 명세와 함께 주어지는 언어별 지시에 있다.
- dist 는 호출자가 할당한다. 초기 내용은 임의의 값(미정의 유한값이며 0 도 −1 도 아니다)이고 사용해서는 안 된다. 함수는 dist[0] = 0 과 도달 불가 정점의 −1 을 포함해 dist 의 **모든** 원소를 써야 한다. 호출 전 dist 에 있던 값에 더하거나 다른 방식으로 결합해서는 안 된다.
- 결과는 반드시 dist 에 써야 한다. 함수의 반환값은 무시된다. 결과는 오직 버퍼 dist 에서만 읽으므로, dist 를 채우지 않고 새 배열을 반환하는 것은 dist 를 쓰지 않은 것으로 간주된다.
- `row_ptr` 와 `col_idx` 는 읽기 전용이다. 일시적으로라도 수정해서는 안 된다.
- 함수 안에서 임시 메모리(큐·프론티어·방문 표시 등 작업 버퍼)를 할당할 수 있으나 반환 전에 해제해야 한다.
- 메모리: 함수를 호출하는 프로세스는 입력·출력을 포함해 주소 공간 8 GiB 로 제한된다. 이를 넘는 할당은 호출 실패로 처리된다. n = 2,097,152 에서 밀집 n×n 인접 행렬은 이 한도에 들어가지 않는다.
- 함수는 파일을 읽거나 쓰지 않고, 네트워크를 쓰지 않고, 표준 출력·표준 오류에 아무것도 출력하지 않고, 환경변수를 읽거나 바꾸지 않고, 전역·정적 가변 상태에 의존하거나 이를 변경하지 않는다. 호출 사이에 상태를 유지하지 않는다.
- 함수는 같은 프로세스에서 같은 버퍼 또는 다른 버퍼로 여러 번 호출된다. 모든 호출은 단독으로 완전하고 올바른 결과를 내야 하며, 같은 입력에 대한 두 호출의 결과는 동일해야 한다.
- 함수는 모든 유효한 CSR 입력에 대해 올바라야 한다. n = 1, 간선이 전혀 없는 그래프(nnz = 0), 빈 행, 바깥 간선이 없는 정점 0, 정점 0 에서 도달할 수 없는 정점, 자기 루프, 2·4·8·16 또는 그 밖의 어떤 블록 크기의 배수도 아닌 크기를 포함한다.

## 정확도

거리는 정확한 정수이므로 허용오차는 없다. 출력은 같은 입력으로 계산한 참조 거리와 원소별로 비교되며, 모든 0 ≤ v < n 에 대해

    dist[v] == ref[v]

일 때만 통과한다. ref[v] 는 정점 0 에서 도달할 수 없는 모든 정점에 대해 −1 이다. 단 하나의 원소라도 다르면(−1 로 쓰지 않은 도달 불가 정점 포함) 검사에 실패한다.

## 평가

- 정확성 형태 (n, nnz): (7, 13), (1,003, 15,833), (65,536, 1,045,504). 첫 그래프는 바깥 차수가 0 ~ 2 이고 정점 0 에서 도달할 수 없는 정점을 포함한다. 나머지 둘은 모든 정점의 바깥 간선이 0 ~ 32 개(평균 약 16)이고 그 대상은 정점 범위 전체에 퍼져 있다.
- 성능 형태 (n, nnz): (2,097,152, 33,541,983). 바깥 차수는 0 ~ 32(평균 약 16), 대상은 정점 범위 전체에 퍼져 있고, 정점 0 에서의 탐색은 몇 레벨 안에 거의 모든 정점에 도달한다. 성능 형태의 출력도 정확 일치 검사를 통과해야 한다.
- 절차: 각 정확성 형태마다 함수를 입력의 새 복사본으로 두 번 호출하고, 매 호출 전 dist 를 임의의 값으로 채운다. 각 출력은 참조와 정확히 같아야 하고 두 출력은 서로 동일해야 한다. 버퍼 밖 쓰기와 입력 변경은 탐지되며 실패로 간주된다.
- 모든 정확성 검사를 통과하면 성능 형태에서 시간을 잰다: 워밍업 3회 뒤 측정 10회, 측정값의 중앙값이 보고되는 실행 시간이다. 함수 호출 시 입력은 이미 메모리에 있고, 측정 시간은 호출 자체의 지속 시간이다.
- 평가에 쓰는 하드웨어·스레드 수·빌드 설정은 언어별 지시에 있다.

## 목표

위 모든 규칙을 지키면서 성능 형태에서 가능한 한 가장 빠른 올바른 구현을 제공한다. 모든 형태에서의 정확성이 속도보다 우선한다: 어떤 정확성 검사라도 실패한 구현은 성능 결과를 받지 못한다.
